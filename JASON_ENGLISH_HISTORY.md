# Jason’s English history

Both English sets now use the same private learning-event journal as Maths and Thinking Skills. City Animals (Q20–25) and Matching Texts (Q26–33) register full question wording, choices/writers, passage context, answer keys and explanations. Each change records the selected option and correctness, while the saved reading snapshot retains first-selection evidence and a timestamped local revision history. Clearing an answer is recorded without declaring it an incorrect first attempt. Original first-selection evidence is carried on later-device events so report generation can preserve it if the original journal event has not yet arrived.

Each static set permits one submission, so its practice ID is stable across devices (`reading-v1-set-1` / `reading-v1-set-2`). Merely opening a set does not emit a new attempt-start or completion event. New starts are recorded on answer/note interaction. Submission records all question results and one completion; repeat clicks cannot resubmit or unlock answers. Passage/question/notes elements are bound to the existing idle-aware estimated-active-viewing timer; this is an estimate, not an exact examination clock. Reading-note changes remain ungraded writing, including review notes after submission.

Answer edits and notes now trigger automatic cloud uploads. Opening, reconnecting, focusing and leaving the English page retries unsynced drafts. Newer answer timestamps prevent stale remote drafts from replacing newer local work; earliest known first-selection evidence and unique local revision events survive merging. Submitted records remain authoritative. Locked/offline work stays on the original device until authenticated syncing is available. Both manual Save buttons are removed; Submit remains because it checks and locks work. Existing parent cloud access controls remain available.

Existing saved answers/submissions are retained. Old entries without recorded first-selection evidence are imported as unknown first attempts. A saved original submission date and final score are used when available; no original first score, historic reading time or missing change is invented. Imported submissions can appear in Notion as completed on their original saved date, with no fabricated start date. Raw imports and readable reports preserve their saved answers.

The existing D1 history endpoint accepts the new records without new bindings or manual SQL. GitHub/Notion automation still requires its separately configured server credentials. Redeploy this PR’s Worker source to receive the improved snapshot-first/legacy-import report interpretation; browser history recording and queueing use the existing endpoint. This implementation does not verify existing production D1 contents.

Cases cover both English sets, wrong-first/later-right, clearing, unknown legacy data, imported source dates, notes after submission, locked access and submission guards.
